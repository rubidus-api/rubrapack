# rubrapack 매뉴얼

English: [`../manual/`](../manual/README.md).

- [`rpk.md`](rpk.md) - 사용자 매뉴얼: 원본 파일(`.toml`, TOML 의 엄격한 부분집합)과 `rubrapack` 명령줄.
- [`formats/`](formats/README.md) - 파일 형식 매뉴얼: Windows Installer 와 MSIX 패키지, 그 캐비닛,
  레지스트리 하이브, 서명이 바이트 단위로 어떻게 짜이는지. rubrapack 의 코드를 읽지 않고도 누구나
  자기 패키지 작성기나 판독기를 만들 수 있도록 썼다.

영어판과 한국어판을 책 한 권으로 묶은 것(웹, PDF): <https://rubidus-api.github.io/rubrapack/>.
[`../manual/book/build.py`](../manual/book/build.py) 가 이 파일들로 그 책을 만든다(`python3 manual/book/build.py`; PDF 에는
Typst 와 스크립트에 적힌 글꼴이 필요하다).

영어판이 원본이고 이 한국어판은 그 번역이다. 둘이 어긋나면 영어판을 따른다. 이 폴더의 모든 글은 코드와
같은 MIT 라이선스를 따른다.

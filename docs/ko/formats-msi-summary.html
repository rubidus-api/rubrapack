코드 페이지 함정 - 요약 문자열은 ASCII 로 [observed]

속성 1(CodePage, VT_I2)은 LPSTR 바이트의 인코딩을 말한다. Windows 11 25H2 에서:

  • 65001: msi.dll 은 문자열을 UTF-8 로 제대로 쓰지만, 코드 페이지를 부호 있는 값 -535 로 다시 읽어 모든 문자열 변환에 실패하고(설치 로그: "Failed to retrieve # 9 summary info property. GetLastError returned 87, the code page is -535") 오류 1620 으로 패키지를 거부한다.
  • 1200(UTF-16): 똑같이 거부한다(로그: "... the code page is 1200"). [MS-OLEPS]대로 완전한 UTF-16 문자열과 바이트 수를 써도 그렇다.
  • 코드 페이지 속성 없음, ASCII 문자열: 설치된다.

그러니 속성 1 은 빼고 요약 문자열은 모두 ASCII 로 쓴다. 지역화한 제품 이름은 데이터베이스 코드 페이지를 쓰는 Property 표(ProductName)에 둔다 - 거기서는 65001 이 통한다(복합 파일 속의 MSI 데이터베이스 참고).

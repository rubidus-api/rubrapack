rubrapack

A command-line tool that builds and signs Windows installer packages - MSI and MSIX - on Windows and Linux.
Windows 설치 패키지(MSI·MSIX)를 Windows 와 Linux 에서 만들고 서명하는 명령줄 도구.

Manual · 매뉴얼 (0.1.0)

  • English (original): web · PDF
  • 한국어: 웹 · PDF

Part I is the user manual (the .rpk source and the command line); Part II the file format manual - the compound file, the MSI database, cabinets, Authenticode, MSIX packages, bundles and signatures, registry hives - written so that anyone can implement these formats without reading rubrapack.
제1부는 사용자 매뉴얼(.rpk 원본과 명령줄), 제2부는 파일 형식 매뉴얼 - 복합 파일, MSI 데이터베이스, 캐비닛, Authenticode, MSIX 패키지·묶음·서명, 레지스트리 하이브 - 이다. rubrapack 을 읽지 않고도 이 형식들을 구현할 수 있게 썼다.
